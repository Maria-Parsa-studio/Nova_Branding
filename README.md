# Nova_Branding
Novva concept website

Contact form
The contact form is configured to use FormSubmit (https://formsubmit.co/) to deliver enquiries to topfreelancer888@gmail.com. On the first live submission, FormSubmit normally sends an activation email to that inbox. Open that email and confirm the activation before expecting messages to be delivered. Test the form after publishing. This uses a third-party form processing service; review its privacy terms before production use.

Important
The provider's default success page is used after submission. You can later replace it with a custom thank-you page.
This is a concept portfolio website, not a representation of completed client work.
